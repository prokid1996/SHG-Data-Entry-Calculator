# SHG Data Entry & Loan Calculator

AdSense-ready, SEO-friendly static website for SHG data entry and basic loan/interest calculations.

## AdSense setup
1. Get your Google AdSense Publisher ID (`ca-pub-...`).
2. Replace `YOUR_PUBLISHER_ID` in the commented AdSense script in `index.html`.
3. Replace the placeholder in `ads.txt` with your real publisher ID.
4. Add/verify the site in Google AdSense and enable Auto Ads after approval.

**Do not use a fake publisher ID.**

## SEO
Includes `robots.txt`, `sitemap.xml`, meta description, canonical URL, Privacy Policy and Terms pages.

## Deploy
Upload the project files to GitHub and connect the repository to Vercel.
