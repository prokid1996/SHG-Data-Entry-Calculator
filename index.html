சுய உதவிக் குழு உறுப்பினர்களின் சேமிப்பு, கடன், தவணை, வட்டி மற்றும் மொத்த வரவு ஆகியவற்றை எளிதாக பதிவு செய்து கணக்கிட இந்த calculator பயன்படுகிறது.

Calculator Features

  • 20 உறுப்பினர்களுக்கான data entry

  • Save, Load மற்றும் Print வசதி
